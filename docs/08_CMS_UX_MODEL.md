## Editor model

Editors should always see:

- canonical owner;
- source version;
- editable versus read-only fields;
- current published value;
- draft value;
- incoming source proposal;
- conflict state;
- publication impact;
- affected routes.

## Page editor

The page editor is not a blank canvas. It offers:

- approved section types;
- approved variants;
- entity and asset references;
- CTA configuration;
- visibility rules;
- mobile and desktop preview.

## Product editor

Use a split view:

- left: operational truth;
- center: public presentation draft;
- right: readiness, itinerary intelligence, conflicts, and publication effect.

## Source sync center

Each source release shows:

- version and commit;
- manifest/checksum status;
- record counts;
- added/changed/removed records;
- mappings;
- conflicts;
- promotion decision;
- rollback action.
