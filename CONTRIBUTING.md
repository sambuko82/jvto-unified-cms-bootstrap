# Contributing

## Pull request requirements

- State the phase and acceptance criterion addressed.
- Include migration and rollback notes for database changes.
- Include tests for ownership, precedence, permissions, and publication behavior.
- Do not include production secrets or copied source payloads containing private data.
- Keep changes additive until migration safety is proven.

## Commit conventions

- `feat(cms): ...`
- `feat(integration): ...`
- `feat(db): ...`
- `fix(governance): ...`
- `docs: ...`
- `test: ...`
- `chore: ...`
